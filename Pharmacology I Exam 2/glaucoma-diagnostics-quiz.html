Before you begin

Every glaucoma drug sorts by whether it reduces aqueous PRODUCTION or increases OUTFLOW, and the alpha agonists sit on both sides, which is where most errors come from. Each class then carries one fact that decides whether a given patient can have it — asthma for the non-selective beta blockers, age under two for the alpha agonists, visual blurring for the cholinergics. Anaesthetics, cycloplegics and fluorescein close the lecture. What this lecture does not test. Dr. Wood rules four things out in as many words: dosing (“not for memorization sake… you can always look up the dosing if you know which drug you actually want to use in the first place”), formulations, the indications table (“don’t worry so much about indications for use… a lot of them have a lot of crossover”), and which agent causes which adverse effect (“any of these can do that”). Nothing here is built on any of it. What is left is mechanism, drug CHOICE, and the handful of facts he stops to make — which is why these sets are 20 and 16 rather than the usual 30.
